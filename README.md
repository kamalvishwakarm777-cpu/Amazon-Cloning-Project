# 🛒 Amazon Clone

A frontend **Amazon Clone** created as my first cloning project while practicing and improving my **Web Development skills**.

This project is built to understand how a large e-commerce website is structured and to practice creating reusable UI components, responsive layouts, navigation, product cards, and other common e-commerce features.

> 🚀 **This project is created for educational and practice purposes only. It is not affiliated with or endorsed by Amazon.**

---

## 📌 Project Overview

The **Amazon Clone** is a practice e-commerce website inspired by the design and user experience of Amazon.

The main goal of this project is to strengthen my understanding of:

* HTML structure
* CSS styling and layouts
* JavaScript functionality
* Responsive web design
* E-commerce UI design
* Reusable components
* Navigation and product sections
* Git & GitHub workflow
* Project organization

This project represents one of my first steps toward becoming a better **Frontend/Web Developer**.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/Amazon-Cloning-Project.git
```

### 2. Open the Project

```bash
cd Amazon-Cloning-Project
```

### 3. Open in VS Code

```bash
code .
```

### 4. Run the Project

If the project is made using HTML, CSS and JavaScript, you can simply open:

```text
index.html
```

in your browser.

Alternatively, if you are using VS Code, you can use the **Live Server** extension to run the project.
